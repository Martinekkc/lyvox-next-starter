# LYVOX Next Starter

A modern open-source Next.js starter for agencies, freelancers, and small businesses that need a clean, SEO-ready website foundation without starting from scratch.

This starter is designed for building fast landing pages, business websites, portfolio sites, and client projects with a professional structure, reusable components, and Vercel-ready deployment.

## Purpose

Most small business websites need the same core foundation:

- clean landing page structure
- strong SEO setup
- responsive layout
- reusable sections
- fast performance
- simple deployment
- easy customization

LYVOX Next Starter provides a practical starting point for developers and small agencies who want to build professional websites faster while keeping the codebase clean and maintainable.

## Features

- Next.js App Router structure

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Martinekkc/lyvox-next-starter.git
```

Go into the project folder:

```bash
cd lyvox-next-starter
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local project in your browser:

```bash
http://localhost:3000
```

## Why This Exists

This project was created from real agency workflow needs.

When building websites for small businesses, freelancers, and local brands, the same foundations are often rebuilt again and again. This starter is meant to reduce repetitive setup work and provide a clean base that can be customized for different projects.

The goal is to make it easier for developers to ship polished, fast, and SEO-ready websites.
